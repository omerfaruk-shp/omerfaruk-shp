#### 🐚 [shp-racon](https://github.com/omerfaruk-shp/shp-racon) — *Custom Shell & Racon Framework*

- **Key Features:** Customized command execution, efficient script automation, and optimized terminal ergonomics.

- **Tech Stack:** Python, Playwright (Headless Browser), Pandas, Excel Export.
- **Key Features:** Bypasses dynamic web restrictions, extracts high-intent lead data (phone, website, rating), and exports directly to structured spreadsheet formats.
