## 🚀 Bazı Projelerim

- **Ömerinho (CLI Yapay Zeka Asistanı)**  
  Terminalde çalışan, GPT tarzı yanıt verebilen yapay zekâ sohbet botu.  
  `gpt4all`, `llama3`, `groq` gibi modellerle çalışıyor.
